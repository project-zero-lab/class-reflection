# ✓ Class Reflection — Teacher Workspace

> A quick post-class reflection tool for teachers to track engagement, flag students who need support and plan follow-ups.

**Live:** https://project-zero-lab.github.io/class-reflection/

**Built by:** Harshit Bhatt · Project Zero × Claylab Education Foundation (Cohort 1)

## What it does
- Records a reflection for each class and subject in about two minutes
- Rates student engagement, participation, understanding and lesson completion
- Flags students needing attention, each with a reason
- Adds a short note and picks the next action: revision, individual support, extra practice, parent follow-up or none
- Shows a dashboard with total reflections, students flagged, pending follow-ups and classes covered
- Searches and filters history by student, date, class, subject and attention
- Exports a JSON backup or CSV, and imports a backup file

## How to use
1. Open the live link
2. Tap **＋ Start a new reflection**
3. Select the class and subject
4. Choose a rating for each of the four rows
5. Add any students who need support and pick a reason for each
6. Add a note (optional) and choose what happens next
7. Tap **Save reflection**
8. Open **History** to search, edit, delete or export your reflections
